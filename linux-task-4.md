1. Modes in Vim
i → Insert mode (start typing)
Esc → Back to Normal mode
v → Visual mode (select text)
🔹 2. Save & Exit
:w → Save file
:q → Quit
:wq → Save and quit
:q! → Force quit (discard changes)
🔹 3. Navigation
h → Left
l → Right
j → Down
k → Up
gg → Go to top
G → Go to bottom
0 → Start of line
$ → End of line
🔹 4. Editing
x → Delete character
dd → Delete line
yy → Copy line
p → Paste
u → Undo
Ctrl + r → Redo
🔹 5. Insert Shortcuts
o → New line below
O → New line above
A → Insert at end of line
I → Insert at beginning
🔹 6. Search & Replace
/text → Search forward
n → Next match
:%s/old/new/g → Replace all
🔹 7. Visual Mode
v → Select characters
V → Select full line
d → Delete selection
y → Copy selection
🔹 8. Useful Power Commands
:set number → Show line numbers
:syntax on → Enable syntax highlighting
:noh → Clear search highlight
